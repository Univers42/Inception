Visit the WordPress site →

What this is

The Inception subject's bonus list asks for "a simple static website in the language of your choice except PHP." This is that service: its own Dockerfile, its own container, its own image (staticsite:inception), on its own port — independent from the mandatory NGINX / WordPress / MariaDB trio. It shares nothing with them except the Docker host.

What it's built with

HTML

Semantic markup, no template engine, no server-side rendering.

CSS

Hand-written, system font stack only — nothing fetched from a CDN.

JavaScript

Vanilla, no framework — the hero typing effect, the clock and the background canvas below are all it does.

NGINX

Serves the three files above and nothing else — no PHP handler is configured in this container.
