The site is meant to grow. The repository seeds its foundations, and a maintainer adds to it from the browser. This is the whole routine.

Sign in

Open /wp-admin/, or Sign in on the landing page, and use the administrator's email (or username) and password. There is no public sign-up: every account is created by a maintainer. The dashboard opens on two panels. Write for Inception is one click to a new post or a new wiki page. The network asks every service of the stack, from inside the WordPress container, whether it answers.

Write a post

Posts → Add New. Give it a category, write, publish. Three headings or more and Easy Table of Contents adds an "On this page" box. Code Block Pro's block highlights code, titles and descriptions for search engines come from The SEO Framework, and Relevanssi indexes the post the moment it is saved, so the site search finds it next to the wiki.

Add a wiki page

New wiki page (or Docs → Add New). In Page Attributes, pick its Parent, the area it belongs to, and its Order in that area. It appears at /wiki/<area>/<page>/, in the area's sidebar tree, between its neighbours' "previous" and "next" links, and in search. Arrange the wiki opens weDocs' own view of the whole tree.

Draw a diagram

Insert the Diagram (Mermaid) pattern from the Inception Kit patterns. It is a code block with the class mermaid: write a diagram as text, and the page draws it, in the site's colours, light or dark. The same syntax works in the repository's Markdown, where GitHub draws it too.

What the repository keeps

Most of the wiki is cut from the project's own documentation by make wiki, and this guide series lives in the repository too. Both are synced on every boot: a page is created when it is missing and refreshed when the repository changed it, until someone edits it in wp-admin. From then on, the edit wins and the next deploy leaves it alone. Plugins are pinned in site/plugins.txt and built into the image, and wp-admin has no code editor, so a change to code always goes through the repository and its tests.
