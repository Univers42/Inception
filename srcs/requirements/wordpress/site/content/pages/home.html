A small infrastructure built with Docker Compose for the 42 Inception project. nginx is the only door, on port 443 with TLS 1.2 and 1.3 only; WordPress runs behind it on php-fpm, and MariaDB keeps its database. Each runs in its own container, built from this repository's Dockerfiles on Alpine 3.23, and both volumes live under /home/dlesieur/data.

The bonus services sit beside them: a Redis object cache, an FTP server on the site's files, Adminer, a database backup every six hours, the landing with its 3D descent, and the lab.
