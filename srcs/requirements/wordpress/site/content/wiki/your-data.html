There are three volumes, each a named Docker volume bound to a directory under /home/dlesieur/data:

Data Host path Docker volume Used by
Database /home/dlesieur/data/mariadb inception_db_data mariadb
Website files /home/dlesieur/data/wordpress inception_wp_data wordpress (read-write), nginx (read-only), ftp (read-write)
Database backups /home/dlesieur/data/backups inception_backup_data dbbackup

Three services share the WordPress volume, which is why a file uploaded over FTP shows up on the website immediately — it is the same directory. nginx mounts it read-only: it serves those files but can never modify them.

Data survives make down / make up cycles and reboots.

To erase everything (containers, images, volumes, and this host data) and start completely fresh:

make clean && make

(or make re, which does the same thing). This does not touch secrets/ or srcs/.env — delete those yourself first if you also want brand-new random passwords and a freshly issued certificate.
