make          # == make up : setup + build + start

The Makefile is the single orchestrator (subject requirement: it must build the images through docker-compose.yml). make up does, in order:

  1. setup — data dirs, .env, secrets, /etc/hosts, TLS material (§1.2).
  2. docker compose -f srcs/docker-compose.yml up -d --build — builds the three images from their Dockerfiles (in parallel, with BuildKit) and starts the stack; the dependency chain is gated by real healthchecks (§6.4).
