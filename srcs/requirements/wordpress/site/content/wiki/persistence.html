Docker volume Host path Contents
inception_db_data /home/dlesieur/data/mariadb MariaDB data directory
inception_wp_data /home/dlesieur/data/wordpress WordPress core, themes, plugins, uploads

Both are named volumes declared at the top level of docker-compose.yml with driver: local and a device option pointing at the host directory. This satisfies both subject rules at once: they are real named volumes (services never bind-mount a host path), and their data lives inside /home/login/data. They survive make down / make up cycles and reboots — make test-deep proves it by writing a DB row and a file, cycling the stack, and reading them back.

Note: the MariaDB host directory ends up mode 750 owned by the container's mysql uid — inspect its content via docker exec mariadb ls /var/lib/mysql, not the host path.
